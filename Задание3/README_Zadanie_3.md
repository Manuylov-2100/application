## Описание программы

Программа реализует калькулятор с графическим интерфейсом на базе стандартной библиотеки tkinter. Калькулятор поддерживает два режима работы: стандартный и расширенный. Переключение между режимами осуществляется кнопкой с символом меню, расположенной на самом калькуляторе. При переходе в расширенный режим окно расширяется: появляются дополнительные кнопки, многострочный дисплей истории и панель выбора ячеек памяти. При возврате в стандартный режим интерфейс возвращается к исходному виду.

Программа написана с применением принципов объектно-ориентированного программирования. Весь калькулятор реализован в виде класса Calculator, наследующего от tk.Tk. Логика построения выражения, его предобработка и вычисление полностью инкапсулированы внутри класса.

## Структура класса Calculator

Класс содержит следующие основные атрибуты и методы:

Атрибуты:
- mode - текущий режим работы ("standard" или "advanced")
- expression - строка текущего вводимого выражения
- memory - список из одной ячейки памяти для стандартного режима
- memory_advanced - список из четырёх ячеек памяти для расширенного режима
- memory_index - индекс активной ячейки памяти в расширенном режиме
- lg10_open, sinh_open - флаги открытой функции с незакрытой скобкой
- history - список строк истории вычислений

Методы:
- create_standard_widgets() - создаёт интерфейс стандартного режима
- create_advanced_widgets() - создаёт интерфейс расширенного режима
- toggle_mode() - переключает между режимами
- on_click_standard() - обрабатывает нажатия кнопок в стандартном режиме
- on_click_advanced() - обрабатывает нажатия кнопок в расширенном режиме
- handle_memory_standard() - выполняет операции с памятью в стандартном режиме
- handle_memory_advanced() - выполняет операции с памятью в расширенном режиме
- preprocess_expression() - преобразует пользовательское выражение в выражение Python
- format_result() - форматирует результат вычисления
- should_autoclose() - определяет, нужно ли автоматически закрыть скобку функции
- close_function_parentheses() - добавляет закрывающую скобку к открытой функции
- add_history() - добавляет запись в историю и обновляет её отображение
- update_history() - перерисовывает содержимое многострочного дисплея истории
- on_memory_select() - синхронизирует выбранную ячейку памяти с RadioButton

## Функциональные возможности

### Стандартный режим

- Арифметические операции: сложение (+), вычитание (-), умножение (*), деление (/)
- Ввод отрицательных чисел через кнопку +/-
- Возведение в степень (x^y)
- Извлечение квадратного корня (√)
- Ввод десятичной точки
- Удаление последнего введённого символа (←)
- Кнопка сброса (C) и кнопка вычисления (=)
- Работа с одной ячейкой памяти: MC, MR, MS, M+, M-

### Расширенный режим

В дополнение к стандартному:

- Многострочный дисплей истории вычислений на 5 строк с возможностью прокрутки
- Четыре независимые ячейки памяти (M1, M2, M3, M4), переключаемые радиокнопками
- Скобки для группировки выражений (кнопка "()")
- Остаток от деления (mod)
- Гиперболический синус (sinh)
- Десятичный логарифм (lg10)
- Корень y-й степени из числа x (y√x)

### Система памяти

В стандартном режиме доступна одна ячейка памяти. В расширенном режиме доступны четыре независимые ячейки M1-M4. Активная ячейка выбирается радиокнопками. Значение в памяти сохраняется при переключении между ячейками.

Назначение кнопок памяти:
- MS (Memory Store) - сохранить текущее значение дисплея в активную ячейку
- MR (Memory Recall) - вставить значение из активной ячейки в выражение
- M+ (Memory Add) - прибавить текущее значение дисплея к значению в активной ячейке
- M- (Memory Subtract) - вычесть текущее значение дисплея из значения в активной ячейке
- MC (Memory Clear) - обнулить активную ячейку памяти

## Принцип работы

Выражение строится посимвольно по мере нажатия кнопок и накапливается в атрибуте self.expression. При нажатии кнопки "=" выражение передаётся в метод preprocess_expression, который выполняет следующие преобразования:

- √N заменяется на math.sqrt(N)
- lg10( заменяется на math.log10(
- sinh( заменяется на math.sinh(
- ^ заменяется на ** (оператор возведения в степень Python)
- выражения вида N mod M заменяются на (N % M)
- выражения вида Y y√x X заменяются на (X ** (1/Y))

После предобработки выражение вычисляется через eval с ограниченным пространством имён, в котором доступен только модуль math.

Метод should_autoclose определяет, нужно ли автоматически закрыть скобку текущей открытой функции (lg10 или sinh) перед вставкой следующего символа. Метод close_function_parentheses добавляет закрывающую скобку, если пользователь не сделал этого вручную.

История вычислений хранится в списке self.history. В расширенном режиме последние 5 записей отображаются в виджете tk.Text. Каждая запись имеет вид: выражение = результат.

## Обработка ошибок

При вводе некорректных операций на дисплей выводится сообщение об ошибке, и эта же запись фиксируется в истории:

- При делении на ноль выводится "Деление на 0"
- При любой другой некорректной операции (например, корень из отрицательного числа, синтаксическая ошибка) выводится "Ошибка"
