Задание 4: Ханойские башни с визуализацией:

Параметры задачи:
- ID: 70210562
- Количество шпинделей: 8
- Количество дисков: 23

Начальное состояние:
- Диски распределены по шпинделям согласно цифрам ID (шпиндель 8 содержит 7 дисков, шпиндель 7 — 0, шпиндель 6 — 2 и т.д.)
- Максимальное количество итераций: 5000

Описание программы:
Программа реализует визуализацию модифицированной задачи о Ханойских башнях с графическим интерфейсом на основе библиотеки tkinter. Визуализация отображает состояние 8 шпинделей в любой момент выполнения задачи, задаваемый через процент от общего числа итераций.

Файлы проекта:
- exercise_4.py — основная программа с визуализацией
- README_Zadanie_4.md — данное описание
- test_scenarios_hanoi - описание примера тестовых команд

Структура начального состояния:
Начальное состояние формируется на основе ID. Каждая цифра ID определяет количество дисков на соответствующем шпинделе (от шпинделя 8 до шпинделя 1). Диаметр каждого диска вычисляется как: номер шпинделя * 10 + позиция диска.

Визуализация:
- Графическое отображение всех 8 шпинделей на холсте
- Цветные диски различного диаметра с числовыми подписями
- Пастельная цветовая палитра, назначаемая дискам при инициализации
- Подписи номеров шпинделей под каждым столбиком

Управление состоянием
- Кнопка перехода к начальному состоянию (0% итераций)
- Кнопка перехода к конечному состоянию (100% итераций)
- Четыре поля ввода для отображения промежуточных состояний по произвольному проценту
- Значения по умолчанию для полей берутся из пар цифр ID: 70%, 21%, 05%, 62%

Вычисление промежуточного состояния:
Метод get_state_at_iteration() вычисляет состояние шпинделей для произвольного момента:
- Прогресс вычисляется как отношение текущей итерации к максимальному числу итераций
- Количество перемещённых дисков определяется как целая часть от (total_disks * progress)
- Перемещённые диски (наименьшие по диаметру) помещаются на шпиндель 1
- Оставшиеся диски распределяются по шпинделям 8, 7, 6, 5, 4, 3, 2 в порядке убывания диаметра

Запуск программы:
- python exercise_4.py

Просмотр состояний:
1. При запуске отображается начальное состояние (итерация 0)
2. Кнопка "Начало (0%)" возвращает к начальному состоянию
3. Кнопка "Окончание (100%)" переходит к конечному состоянию
4. Для просмотра промежуточного состояния введите процент в одно из четырёх полей и нажмите "Показать" или Enter

- Рекомендуемое разрешение экрана: 1300x850 и выше
